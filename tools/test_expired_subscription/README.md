# Тест системы проверки истекших подписок

Этот инструмент позволяет проверить состояние подписок пользователей и найти те, которые истекли, но еще не были отключены.

## Использование

```bash
cd /root/bot/tools/test_expired_subscription
go run main.go
```

## Что делает инструмент

1. Подключается к базе данных
2. Получает всех пользователей с активными конфигами
3. Проверяет, какие подписки истекли
4. Выводит подробный отчет о состоянии подписок
5. Показывает настройки системы проверки

## Пример вывода

```
=== Тест системы проверки истекших подписок ===
Найдено пользователей с активными конфигами: 15

=== Проверка подписок ===
❌ Истекшая подписка: Иван (ID: 123456789, Email: ivan@example.com, Истекла: 2024-01-01 12:00:00)
✅ Активная подписка: Мария (ID: 987654321, Email: maria@example.com, Осталось дней: 5)

=== Результаты ===
Всего пользователей с активными конфигами: 15
Истекших подписок: 1
Активных подписок: 14

⚠️  ВНИМАНИЕ: Найдено 1 истекших подписок, которые должны быть отключены!

=== Настройки ===
EXPIRED_SUBSCRIPTION_CHECK_ENABLED: true
EXPIRED_SUBSCRIPTION_CHECK_INTERVAL: 5 минут
```

## Когда использовать

- После внедрения системы проверки истекших подписок
- Для диагностики проблем с подписками
- Для проверки корректности работы системы
- Перед запуском бота для проверки текущего состояния
