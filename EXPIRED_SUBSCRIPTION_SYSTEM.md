# Система автоматического отключения истекших подписок

## Описание

Система автоматически проверяет все активные подписки пользователей и отключает те, время действия которых истекло. Это решает проблему, когда подписки показывают статус "Исчерпано" в панели управления, но остаются активными.

## Настройки

Все настройки находятся в файле `common/config.go`:

### Основные параметры

- `EXPIRED_SUBSCRIPTION_CHECK_ENABLED` - включить/выключить систему проверки истекших подписок (по умолчанию: `true`)
- `EXPIRED_SUBSCRIPTION_CHECK_INTERVAL` - интервал проверки подписок в минутах (по умолчанию: `5` минут)

## Архитектура

### Файлы системы

1. **`common/config.go`** - настройки системы
2. **`services/expired_subscription_service.go`** - основная логика проверки и отключения
3. **`main.go`** - интеграция сервиса в основное приложение
4. **`services/expired_subscription_service_test.go`** - тесты

### Основные компоненты

#### ExpiredSubscriptionService
- `NewExpiredSubscriptionService(bot, configManager)` - создание сервиса
- `Start()` - запуск сервиса с периодическими проверками
- `Stop()` - остановка сервиса
- `checkExpiredSubscriptions()` - проверка всех пользователей
- `isSubscriptionExpired(user, now)` - проверка конкретного пользователя
- `disableExpiredSubscription(user)` - отключение истекшей подписки
- `ForceCheckExpiredSubscriptions()` - принудительная проверка

## Как работает система

1. **Запуск** - сервис запускается при старте бота в отдельной горутине
2. **Периодическая проверка** - происходит каждые `EXPIRED_SUBSCRIPTION_CHECK_INTERVAL` минут
3. **Получение пользователей** - система получает всех пользователей с активными подписками
4. **Проверка истечения** - для каждого пользователя проверяется `ExpiryTime`
5. **Отключение** - если подписка истекла:
   - Конфиг отключается в панели управления через API
   - Статус `HasActiveConfig` устанавливается в `false` в базе данных
   - Пользователю отправляется уведомление
   - Администратору отправляется уведомление

## Критерии истечения подписки

Подписка считается истекшей, если:
- `HasActiveConfig == true` (подписка активна)
- `ExpiryTime > 0` (время истечения установлено)
- `ExpiryTime <= текущее_время` (время истекло)

## Интеграция

### Автоматическая интеграция

Система автоматически интегрирована в:
- **Запуск бота** - сервис запускается при старте приложения
- **Планировщик** - периодическая проверка всех пользователей

### Ручное управление

Для принудительной проверки можно использовать:
```go
// Получить сервис из main.go
if globalExpiredSubscriptionService != nil {
    globalExpiredSubscriptionService.ForceCheckExpiredSubscriptions()
}
```

## Решение проблемы

Эта система решает критическую проблему, описанную пользователем:
- **Проблема**: Подписки показывают статус "Исчерпано" в панели, но остаются активными
- **Решение**: Автоматическое отключение истекших подписок каждые 5 минут
- **Результат**: Синхронизация между статусом в панели и реальным состоянием подписки
