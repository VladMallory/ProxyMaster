# Система безопасного выключения бота

Этот модуль обеспечивает безопасное выключение Telegram бота с защитой активных платежей.

## Возможности

- ✅ **Безопасное выключение** - бот ждет завершения всех активных платежей
- ✅ **Блокировка новых платежей** - предотвращает создание новых платежей во время выключения
- ✅ **Мониторинг активных платежей** - отслеживает состояние платежей в реальном времени
- ✅ **Таймаут защиты** - принудительное выключение через заданное время
- ✅ **Уведомления администратора** - информирует о процессе выключения
- ✅ **Отмена выключения** - возможность отменить процесс выключения

## Настройки в config.go

```go
// === НАСТРОЙКИ БЕЗОПАСНОГО ВЫКЛЮЧЕНИЯ ===
POWEROFF_SYSTEM_ENABLED      bool  // Включена ли система безопасного выключения
POWEROFF_PAYMENT_TIMEOUT     int   // Таймаут ожидания завершения платежей в минутах
POWEROFF_CHECK_INTERVAL      int   // Интервал проверки активных платежей в секундах
POWEROFF_NOTIFICATION_ENABLED bool // Включены ли уведомления о выключении
```

## Команды

### `/poweroff`
Запускает процесс безопасного выключения.

### `/poweroff status`
Показывает текущий статус системы выключения.

### `/poweroff cancel`
Отменяет процесс выключения (только для администратора, который его запустил).

### `/poweroff force`
Принудительное выключение без ожидания завершения платежей.

## Как это работает

1. **Админ вводит `/poweroff`** → система переходит в режим подготовки
2. **Блокируются новые платежи** → пользователи получают уведомление о недоступности
3. **Мониторинг активных платежей** → система проверяет каждые 10 секунд
4. **Ожидание завершения** → бот ждет завершения всех активных платежей
5. **Безопасное выключение** → когда все платежи завершены, бот выключается
6. **Таймаут защиты** → если платежи не завершились за 5 минут, принудительное выключение

## Интеграция

### Инициализация
```go
import "bot/powerOff"

// В main.go или app/init.go
powerOff.InitializePowerOffSystem()
```

### Обработка команд
```go
// В handlers/message_handler.go
case "poweroff":
    powerOff.HandlePoweroffCommand(bot, message)
```

### Обработка callback'ов
```go
// В handlers/callback_handler.go
if powerOff.IsPoweroffCallback(data) {
    powerOff.HandlePoweroffCallback(bot, callback)
    return
}
```

### Защита платежей
```go
// В handlers/payment_handler.go
func ProcessTopup(bot *tgbotapi.BotAPI, chatID int64, messageID int, user *common.User, amount int) {
    // Проверяем, заблокированы ли платежи
    if allowed, message := powerOff.CheckPaymentAllowedGlobal(); !allowed {
        powerOff.SendPaymentBlockedMessageGlobal(bot, chatID, messageID)
        return
    }
    
    // ... остальной код обработки платежей
}
```

## Структура файлов

- `types.go` - определения типов и структур
- `manager.go` - основная логика управления выключением
- `handlers.go` - обработчики команд и callback'ов
- `payment_guard.go` - защита платежей от создания во время выключения
- `init.go` - инициализация системы

## Безопасность

- Только администратор может запустить выключение
- Только тот администратор, который запустил выключение, может его отменить
- Все активные платежи отслеживаются и защищаются
- Принудительное выключение возможно только через специальную команду
- Все действия логируются

## Логирование

Все действия системы записываются в лог с префиксом `POWEROFF:`:

```
POWEROFF: Менеджер безопасного выключения инициализирован
POWEROFF: Запрошено выключение администратором 123456789
POWEROFF: Ожидание завершения 2 платежей
POWEROFF: Все платежи завершены. Выключаем бота...
POWEROFF: Graceful shutdown завершен
```
