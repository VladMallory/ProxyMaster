# Использование системы безопасного выключения

## Настройка

### 1. Включение/выключение системы

В файле `/root/bot/common/config.go`:

```go
// === НАСТРОЙКИ БЕЗОПАСНОГО ВЫКЛЮЧЕНИЯ ===
POWEROFF_SYSTEM_ENABLED = true  // Включена ли система безопасного выключения
POWEROFF_PAYMENT_TIMEOUT = 5    // Таймаут ожидания завершения платежей в минутах
POWEROFF_CHECK_INTERVAL = 10    // Интервал проверки активных платежей в секундах
POWEROFF_NOTIFICATION_ENABLED = true // Включены ли уведомления о выключении
```

### 2. Настройка таймаутов

- `POWEROFF_PAYMENT_TIMEOUT` - максимальное время ожидания завершения платежей (по умолчанию 5 минут)
- `POWEROFF_CHECK_INTERVAL` - как часто проверять активные платежи (по умолчанию 10 секунд)

## Команды

### `/poweroff`
Запускает процесс безопасного выключения.

**Что происходит:**
1. Блокируются новые платежи
2. Проверяются активные платежи
3. Бот ждет завершения всех платежей
4. Безопасно выключается

### `/poweroff status`
Показывает текущий статус системы выключения.

**Информация:**
- Состояние системы (нормальная работа/подготовка/выключение)
- Количество активных платежей
- Время до принудительного выключения
- Кто запросил выключение

### `/poweroff cancel`
Отменяет процесс выключения.

**Ограничения:**
- Только администратор может отменить
- Только тот администратор, который запустил выключение

### `/poweroff force`
Принудительное выключение без ожидания завершения платежей.

**⚠️ Осторожно:**
- Активные платежи могут быть потеряны
- Требует подтверждения

## Сценарии использования

### Сценарий 1: Обычное выключение
```
Админ: /poweroff
Бот: ⚠️ Запрошено безопасное выключение
     Проверяем активные платежи...
     Найдено 2 активных платежей. Ожидаем их завершения...

[через 2 минуты]
Бот: ✅ Все платежи завершены. Выключаем бота...
Бот: 🔌 Бот выключается безопасно...
```

### Сценарий 2: Отмена выключения
```
Админ: /poweroff
Бот: ⚠️ Запрошено безопасное выключение...

Админ: /poweroff cancel
Бот: ✅ Выключение отменено. Система вернулась к нормальной работе
```

### Сценарий 3: Принудительное выключение
```
Админ: /poweroff force
Бот: ⚠️ Принудительное выключение
     Это действие немедленно выключит бота без ожидания завершения платежей.
     Активные платежи могут быть потеряны!
     Вы уверены?
     [✅ Да, выключить принудительно] [❌ Отмена]

Админ: [нажимает подтверждение]
Бот: 🔌 Принудительное выключение...
```

### Сценарий 4: Пользователь пытается оплатить во время выключения
```
Пользователь: [нажимает "Пополнить баланс"]
Бот: ⚠️ Платежи временно недоступны
     Бот готовится к выключению для технических работ.
     Активных платежей: 1
     Время до выключения: 180 сек
     Попробуйте позже.
     [🏠 Главная]
```

## Мониторинг

### Логи
Все действия записываются в лог с префиксом `POWEROFF:`:

```
POWEROFF: Менеджер безопасного выключения инициализирован
POWEROFF: Запрошено выключение администратором 123456789
POWEROFF: Ожидание завершения 2 платежей
POWEROFF: Осталось 1 активных платежей...
POWEROFF: Все платежи завершены. Выключаем бота...
POWEROFF: Graceful shutdown завершен
```

### Статус системы
```go
// Получить статус системы
status := powerOff.GetSystemStatus()
fmt.Printf("Система включена: %v\n", status["enabled"])
fmt.Printf("Инициализирована: %v\n", status["initialized"])
fmt.Printf("Состояние: %v\n", status["shutdown_state"])
```

## Безопасность

### Защита платежей
- Новые платежи блокируются сразу после запроса выключения
- Активные платежи продолжают обрабатываться
- Webhook'и от ЮКассы продолжают работать
- Пользователи получают уведомления о недоступности

### Права доступа
- Только администратор может запустить выключение
- Только тот администратор, который запустил выключение, может его отменить
- Принудительное выключение требует подтверждения

### Таймауты
- Максимальное время ожидания платежей: 5 минут (настраивается)
- Проверка активных платежей каждые 10 секунд (настраивается)
- Автоматическое принудительное выключение при превышении таймаута

## Интеграция с существующим кодом

Система автоматически интегрируется в существующий код:

1. **Инициализация** - в `app/init.go`
2. **Обработка команд** - в `handlers/message_handler.go`
3. **Обработка callback'ов** - в `handlers/callback_handler.go`
4. **Защита платежей** - в `handlers/payment_handler.go`

Никаких дополнительных изменений в основном коде не требуется.
