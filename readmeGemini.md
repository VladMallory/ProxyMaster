# Ключевая информация о проекте

## 1. Суть проекта

Это Telegram-бот, предназначенный для автоматизированной продажи и управления VPN-подписками (VLESS). Он интегрируется с панелью управления `3x-ui` для создания и менеджмента пользовательских конфигураций.

## 2. Основные функциональные возможности

- **Автоматизация подписок**: Бот управляет полным жизненным циклом подписки: создание, продление и отключение пользователей.
- **Биллинг**: Поддерживает две модели оплаты:
  - **Автосписание**: Ежедневное списание фиксированной суммы с баланса пользователя.
  - **Тарифный план**: Возможность покупки подписки на определенный срок (альтернативный режим).
- **Платежные системы**: Принимает оплату через встроенные платежи Telegram и напрямую через API ЮKassa (с возможностью отправки чеков).
- **Управление пользователями**:
  - **Пробный период**: Автоматическое начисление стартового баланса новым пользователям.
  - **Реферальная система**: Пользователи получают бонусы за приглашение друзей.
- **Безопасность и контроль**:
  - **IP Ban**: Система автоматически блокирует конфигурации пользователей, которые превышают лимит одновременных IP-адресов, для предотвращения совместного использования аккаунтов.
  - **Управление трафиком**: Администратор может устанавливать лимиты трафика для пользователей и настраивать автоматический сброс статистики.
- **Администрирование**: Бот предоставляет администратору широкий набор команд для мониторинга (`/users`, `/traffic`) и управления системой (`/backup`, `/switch_tariff`).
- **Фоновые службы**: Проект построен на архитектуре с использованием фоновых сервисов (goroutines), которые выполняют периодические задачи: проверка истекших подписок, контроль IP-адресов, очистка дубликатов и т.д.

## 3. Технологический стек

- **Язык программирования**: Go
- **База данных**: PostgreSQL
- **Панель управления VPN**: 3x-ui
- **Основные зависимости**:
  - `go-telegram-bot-api/v5` — для взаимодействия с Telegram API.
  - `lib/pq` — драйвер для PostgreSQL.
