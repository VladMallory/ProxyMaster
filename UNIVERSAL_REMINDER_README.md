# Система универсальных напоминаний о подписке

## Описание

Система универсальных напоминаний автоматически отправляет пользователям уведомления о приближающемся истечении подписки. В отличие от старой системы с фиксированными сообщениями, новая система использует одно универсальное сообщение с точным временем до истечения.

## Особенности

- **Универсальное сообщение**: Одно сообщение с плейсхолдерами `{DAYS}` и `{HOURS}`
- **Ежедневная проверка**: Раз в сутки проверяет всех пользователей с активными подписками
- **Предотвращение спама**: Не отправляет повторные напоминания в течение дня
- **Точное время**: Показывает точное количество дней и часов до истечения
- **Логирование**: Ведет лог всех отправленных напоминаний

## Настройки в config.go

```go
// ========== УНИВЕРСАЛЬНЫЕ НАПОМИНАНИЯ О ПОДПИСКЕ ==========
UNIVERSAL_REMINDER_ENABLED = true                    // Включить/выключить систему
UNIVERSAL_REMINDER_INTERVAL = 1440                   // Интервал проверки (в минутах, 1440 = 24 часа)
UNIVERSAL_REMINDER_DAYS_BEFORE = 3                   // За сколько дней начинать напоминания
UNIVERSAL_REMINDER_MESSAGE = "⏰ <b>Напоминание о подписке</b>\n\n" +
    "До окончания вашей подписки осталось: <b>{DAYS} дней {HOURS} часов</b>\n\n" +
    "Не забудьте продлить подписку, чтобы не потерять доступ к VPN.\n\n" +
    "Нажмите /balance для просмотра баланса и продления."
UNIVERSAL_REMINDER_LOG_PATH = "/root/bot/logs/reminders.log"  // Путь к логу напоминаний
```

## Принцип работы

1. **Проверка**: Каждые 24 часа система проверяет всех пользователей с активными подписками
2. **Фильтрация**: Отбирает пользователей, у которых подписка истекает в ближайшие N дней (настраивается)
3. **Проверка дубликатов**: Проверяет, не отправлялось ли напоминание пользователю сегодня
4. **Отправка**: Отправляет универсальное сообщение с точным временем до истечения
5. **Логирование**: Записывает факт отправки в лог файл

## Управление

### Включение/выключение

В файле `common/config.go` измените значение:
```go
UNIVERSAL_REMINDER_ENABLED = true  // включить
UNIVERSAL_REMINDER_ENABLED = false // выключить
```

### Настройка интервала

```go
UNIVERSAL_REMINDER_INTERVAL = 1440  // 24 часа (в минутах)
UNIVERSAL_REMINDER_INTERVAL = 720   // 12 часов
UNIVERSAL_REMINDER_INTERVAL = 60    // 1 час
```

### Настройка дней напоминания

```go
UNIVERSAL_REMINDER_DAYS_BEFORE = 3  // Начинать напоминания за 3 дня
UNIVERSAL_REMINDER_DAYS_BEFORE = 7  // Начинать напоминания за неделю
UNIVERSAL_REMINDER_DAYS_BEFORE = 1  // Начинать напоминания за 1 день
```

### Настройка сообщения

Измените `UNIVERSAL_REMINDER_MESSAGE` в config.go. Используйте плейсхолдеры:
- `{DAYS}` - количество дней до истечения
- `{HOURS}` - количество часов до истечения

## Логи

Система ведет подробные логи в файле `/root/bot/logs/reminders.log`. Каждая запись содержит:

```json
{
  "user_id": 123456789,
  "sent_at": "2024-01-15T10:30:00Z",
  "days_left": 2,
  "hours_left": 5,
  "expiry_time": 1705320000000
}
```

## Совместимость

Система работает параллельно со старой системой уведомлений. Если обе системы включены, будут работать обе. Рекомендуется отключить старую систему:

```go
NOTIFICATION_ENABLED = false  // отключить старую систему
UNIVERSAL_REMINDER_ENABLED = true  // включить новую систему
```

## Мониторинг

Система выводит подробные логи в консоль:
- `UNIVERSAL_REMINDER: Запуск сервиса...`
- `UNIVERSAL_REMINDER: Начало проверки подписок...`
- `UNIVERSAL_REMINDER: Напоминание отправлено пользователю X (осталось Y дней Z часов)`
- `UNIVERSAL_REMINDER: Проверка завершена, отправлено N напоминаний`

## Устранение неполадок

### Напоминания не отправляются

1. Проверьте, что `UNIVERSAL_REMINDER_ENABLED = true`
2. Проверьте, что бот инициализирован
3. Проверьте логи на наличие ошибок
4. Убедитесь, что у пользователей есть активные подписки

### Дублирование напоминаний

Система автоматически предотвращает отправку повторных напоминаний в течение дня. Если проблема сохраняется, проверьте лог файл.

### Ошибки в логах

```bash
tail -f /root/bot/logs/reminders.log
```

## Производительность

- Система проверяет всех пользователей с активными подписками
- Время выполнения зависит от количества пользователей
- Логирование происходит асинхронно и не блокирует основную работу
- Старые записи логов автоматически очищаются (старше 30 дней)
