# Исправление частого сброса трафика

## Проблема
Бот сбрасывал трафик панели 3x-ui у всех клиентов чаще чем должен (не только раз в 7 дней).

## Причины
1. **Автосписание**: каждые 30 минут вызывал `ForceResetDepletedStatus` для синхронизации клиентов
2. **Проверка reset**: каждый день сбрасывал флаги `Depleted` и `Exhausted` у клиентов
3. **Перезапуск бота**: при каждом перезапуске сразу сбрасывал трафик (не ждал 7 дней)

## Исправления

### 1. Убрали принудительный сброс из автосписания
**Файл**: `services/auto_billing_service.go`
- Удален вызов `ForceResetDepletedStatus` при обновлении конфигов
- Автосписание теперь только обновляет время истечения, не сбрасывая трафик

### 2. Исправили сервис проверки reset
**Файл**: `services/reset_status_checker.go`
- Убрали сброс флагов `Depleted` и `Exhausted` 
- Теперь только исправляет email и включает отключенных клиентов
- Не считает флаги трафика проблемой (они могут быть true по законным причинам)

### 3. Исправили сброс при перезапуске
**Файл**: `common/database.go`
- Добавлена задержка до следующего запланированного сброса
- При перезапуске бот не сбрасывает трафик сразу, а ждет нужного времени

### 4. Добавили детальное логирование
**Файл**: `common/traffic_logger.go`
- Все операции с трафиком записываются в `/root/bot/logs/traffic.log`
- Можно отслеживать когда и почему происходит сброс трафика

## Результат
Теперь сброс трафика происходит **только раз в 7 дней** через периодический сервис:
- `TRAFFIC_RESET_INTERVAL = 10080` минут (7 дней)
- Автосписание и проверка reset больше не сбрасывают трафик
- При перезапуске бота трафик НЕ сбрасывается сразу

## Мониторинг
```bash
# Смотреть логи трафика
tail -f /root/bot/logs/traffic.log

# Фильтровать по операциям
grep "PERIODIC_TRAFFIC_RESET" /root/bot/logs/traffic.log
grep "FORCE_RESET_DEPLETED" /root/bot/logs/traffic.log
```
