# VPN Бот

Этот проект представляет собой комплексного Telegram-бота, написанного на Go, предназначенного для управления подписками клиентов VPN, платежами и пользовательскими конфигурациями. Он интегрируется с панелью 3x-ui для управления VPN-сервером и использует PostgreSQL для хранения данных.

## Возможности

*   **Интерфейс Telegram-бота**: Интерактивные меню и обработчики для взаимодействия с пользователем.
*   **Управление пользователями**: Регистрация, управление балансом и отслеживание конфигураций.
*   **Управление подписками**: Обработка активных конфигураций, сроков действия и пробных периодов.
*   **Интеграция платежей**: Обработка платежей и логирование транзакций.
*   **Интеграция с панелью VPN**: Автоматическое управление учетными записями клиентов VPN на панели 3x-ui.
*   **Фоновые службы**: Автоматизированные задачи, такие как выставление счетов, резервное копирование и напоминания.
*   **Реферальная система**: Отслеживание и управление реферальными ссылками.
*   **Административные инструменты**: Утилиты командной строки для отладки, очистки и ручных операций.

## Архитектура

Проект имеет модульную архитектуру, построенную в основном вокруг Telegram-бота и нескольких взаимосвязанных служб.

### 1. Основное приложение (`main.go`, `app/`)

*   **`main.go`**: Точка входа в приложение, отвечающая за инициализацию подключения к базе данных, загрузку переменных окружения и запуск Telegram-бота.
*   **`app/init.go`**: Содержит логику инициализации всего приложения.

### 2. Telegram-бот (`telegram_bot/`, `handlers/`, `menus/`)

*   **`telegram_bot/bot.go`**: Инициализирует и запускает Telegram-бота, обрабатывая входящие обновления.
*   **`handlers/`**: Содержит различные обработчики для разных типов сообщений и колбэков Telegram (например, `message_handler.go`, `callback_handler.go`, `payment_handler.go`). Эти модули определяют, как бот реагирует на взаимодействия с пользователем.
*   **`menus/`**: Определяет структуру и логику интерактивных меню, представляемых пользователям в Telegram-боте (например, `main_menu.go`, `vpn_menu.go`, `topup_menu.go`).

### 3. Уровень базы данных (`common/database.go`, `common/postgres.go`, `migrations/`)

*   **PostgreSQL**: Основное хранилище данных для информации о пользователях, подписках и других данных приложения.
*   **`common/database.go`**: Предоставляет уровень абстракции для взаимодействия с базой данных.
*   **`common/postgres.go`**: Содержит функции подключения и утилиты, специфичные для PostgreSQL.
*   **`migrations/`**: Хранит SQL-скрипты для миграций схемы базы данных, обеспечивая актуальность структуры базы данных.
*   **`migrationPosttreSQL/`**: Содержит скрипты и документацию для процессов миграции базы данных PostgreSQL.

### 4. Интеграция с панелью VPN (`common/panel_api.go`, `tools/clean_client/`)

*   **`common/panel_api.go`**: Обрабатывает связь с API панели 3x-ui, включая аутентификацию, создание, изменение и удаление клиентов.
*   **`tools/clean_client/`**: Инструмент командной строки, демонстрирующий прямое взаимодействие с панелью 3x-ui и базой данных бота для управления клиентами (например, удаление клиентов, сброс конфигураций).

### 5. Общие утилиты и менеджеры (`common/`)

Этот каталог является центральным узлом для общих функций и компонентов бизнес-логики:

*   **`analyzer.go`**: Анализ данных или трафика.
*   **`ban_manager.go`**: Управление IP-банами или банами пользователей.
*   **`billing_manager.go`**: Обрабатывает циклы выставления счетов и расчеты.
*   **`config.go`**: Загрузка конфигурации приложения.
*   **`manager.go`**: Общий интерфейс или база менеджера.
*   **`referral_checker.go`**: Логика для проверки реферальных кодов.
*   **`service.go`**: Общий интерфейс или база службы.
*   **`telegram_payments.go`**: Специфическая логика для обработки платежей Telegram.
*   **`traffic_logger.go`**: Логирует данные о трафике пользователей.
*   **`trial_manager.go`**: Управляет пробными периодами для новых пользователей.
*   **`types.go`**: Общие структуры данных и типы.
*   **`utils.go`**: Общие служебные функции.

### 6. Фоновые службы (`services/`)

Набор служб, работающих в фоновом режиме для выполнения автоматизированных задач:

*   **`auto_billing_service.go`**: Автоматизирует процессы выставления счетов.
*   **`backup_service.go`**: Обрабатывает резервное копирование базы данных и конфигурации.
*   **`depleted_status_checker.go`**: Проверяет и обновляет статус исчерпанных учетных записей.
*   **`expired_subscription_service.go`**: Управляет просроченными подписками.
*   **`payment_monitor_service.go`**: Мониторит статусы платежей.
*   **`universal_reminder_service.go`**: Отправляет различные напоминания пользователям.

### 7. Платежная система (`payments/`)

*   **`payments/manager.go`**: Управляет общими потоками платежей.
*   **`payments/webhooks.go`**: Обрабатывает входящие вебхуки платежей от поставщиков платежей.
*   **`payments/payment_logger.go`**: Логирует события, связанные с платежами.

### 8. Система реферальных ссылок (`referralLink/`)

*   **`referralLink/manager.go`**: Управляет созданием, отслеживанием и применением реферальных ссылок.
*   **`referralLink/handler.go`**: Обрабатывает взаимодействия, связанные с реферальными ссылками.

### 9. Инструменты и утилиты (`tools/`, `other/`, `loadTest/`)

*   **`tools/`**: Содержит различные автономные скрипты и утилиты для административных задач, отладки и обслуживания (например, `check_admin_config`, `fix_xray_duplicates`, `ipBanSystem`).
*   **`other/`**: Различные скрипты, резервные копии и одноразовые утилиты.
*   **`loadTest/`**: Содержит скрипты и конфигурации для проведения нагрузочных тестов приложения.Настройка и установка

1.  **Предварительные требования**:
    *   Go (версия 1.21 или выше)
    *   База данных PostgreSQL
    *   Экземпляр панели 3x-ui
    *   `git`
2.  **Клонировать репозиторий**:
    ```bash
    git clone <repository_url>
    cd bot
    ```
3.  **Конфигурация окружения**:
    Создайте файл `.env` в корне проекта на основе `.env.example` (если доступен) и настройте данные для подключения к PostgreSQL, токен Telegram-бота и учетные данные панели 3x-ui.
4.  **Настройка базы данных**:
    *   Убедитесь, что PostgreSQL запущен.
    *   Выполните миграции базы данных, используя скрипты в `migrations/` или `migrationPosttreSQL/`.
5.  **Установка зависимостей**:
    ```bash
    go mod tidy
    ```
6.  **Сборка и запуск**:
    ```bash
    go build -o vpn_bot main.go
    ./vpn_bot
    ```

## Использование

После запуска бота взаимодействуйте с ним через Telegram. Административные инструменты можно запускать из командной строки в каталоге `tools/`.
