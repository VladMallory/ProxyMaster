# Уведомления администратора о напоминаниях

## Описание

Добавлена возможность отправки уведомлений администратору при отправке напоминаний о подписке пользователям.

## Конфигурация

В файле `common/config.go` добавлена новая переменная:

```go
ADMIN_REMINDER_ENABLED = true // Уведомления о отправленных напоминаниях о подписке
```

## Функциональность

### Автоматические уведомления

При отправке напоминания пользователю через универсальный сервис напоминаний, администратор автоматически получает уведомление с информацией:

- 👤 Имя пользователя и ID
- 💰 Текущий баланс
- 📧 Email пользователя  
- ⏳ Оставшееся время до истечения подписки
- 🕐 Время отправки напоминания

### Принудительная отправка

Добавлена команда `force` в инструмент управления напоминаниями:

```bash
cd /root/bot/tools/reminder_manager
go run main.go force <user_id>
```

Эта команда:
1. Проверяет, что у пользователя есть активная подписка
2. Вычисляет оставшееся время
3. Отправляет напоминание пользователю
4. Отправляет уведомление администратору
5. Записывает событие в лог

## Использование

### Просмотр всех команд

```bash
cd /root/bot/tools/reminder_manager
go run main.go
```

### Принудительная отправка напоминания

```bash
go run main.go force 123456789
```

### Проверка статуса пользователя

```bash
go run main.go check 123456789
```

### Просмотр статистики

```bash
go run main.go stats
```

## Отключение уведомлений

Чтобы отключить уведомления администратору о напоминаниях, установите в `common/config.go`:

```go
ADMIN_REMINDER_ENABLED = false
```

## Логирование

Все отправленные напоминания записываются в лог файл:
- Путь: `/root/bot/logs/reminders.log`
- Формат: JSON с информацией о пользователе, времени отправки и оставшемся времени

💰 Баланс: 150.50₽
📧 Email: 123456789
⏳ Осталось: 2 дней 5 часов
🕐 Время отправки: 2024-01-15 14:30:25
